# Specials menu
Dynamic Digital Menu with Google Sheets API
This project is a full-stack solution for restaurants that automates daily menu management without requiring any website code changes.

Data Architecture: Leverages Google Sheets as a NoSQL database, allowing restaurant managers to schedule dishes for the entire week in advance.

Backend (Serverless): Built with Google Apps Script, the engine processes real-time requests, detects the current day of the week, and automatically filters the relevant dishes.


Frontend & UX: Developed with Vanilla JavaScript, featuring Skeleton Screens for a seamless loading experience and CSS Grid for a responsive design that fits any device.

Tech Stack: JavaScript (ES6+), Google Apps Script, Google Sheets API, HTML5, CSS3.
